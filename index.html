거래처 · 품목 · 바코드 · ERP(매입 / 제조라인) · 인증서 등록 흐름과 주의사항

최종 업데이트 : 2026-11-04
📌 읽기 전에 — 이 매뉴얼은 상품마스터 메뉴를 실제로 등록·운영하는 담당자를 위한 안내서입니다. 실제 관리자 화면 캡쳐와 기획서(ERP 상세 화면 정의)를 기준으로 작성했습니다. 화면에 보이는 예시 데이터는 테스트 값일 수 있습니다.
전체 업무 흐름

상품마스터는 거래처(제조사) → 품목 → 바코드 → ERP 순서로 등록합니다. 앞 단계가 끝나야 다음 단계에서 선택할 수 있기 때문에 순서를 지켜야 합니다. 인증서는 별도로 등록해 두고 품목과 연결합니다.

영업관리팀
반드시 확인.
  • 품목 등록 전에 거래처(제조사)를 먼저 등록해야 품목 등록 시 제조사를 선택할 수 있습니다. 제조사가 없으면 거래처관리부터 등록하세요.
  • 이미 있는 품목은 품목관리에 등록되어 있으니 정보를 수정하세요. 신규 제품만 품목 등록 후 바코드를 등록합니다.
  • ERP 등록 전에 품목 안에 바코드가 먼저 등록되어 있어야 ERP 등록 시 품번(바코드)을 선택할 수 있습니다. 바코드가 없으면 품목관리에서 먼저 등록하세요.
메뉴 구조와 담당
메뉴하는 일
① 거래처 관리제조사·공급사를 사전에 등록합니다.
② 인증서 관리할랄·비건 등 인증서 파일과 대상 품목을 등록합니다. 인증 관리 주체 부서가 각자 담당합니다.
③ 품목 관리품목 · 바코드 · 이미지를 등록하고 관리합니다. 바코드/이미지 변경 시 안내 메일이 자동으로 만들어지고, 저장 시 변경 이력이 쌓입니다.
④ ERP 관리바코드 구성을 만들어 ERP 생성을 요청하고, 담당자가 확인 후 최종 생성합니다. 같은 바코드·수량 구성은 중복 등록할 수 없습니다.

08

가격 가이드

상품본부가 정한 가격 가이드 정보를 안내하는 조회 메뉴입니다. 품번으로는 검색되지 않고 품목명(제품명)으로 확인합니다. 별도 안내 페이지 없이 클릭하면 해당 메뉴로 바로 이동합니다.

  • 화면 구성 : [가격표] / [최근 변경] / [이용 안내] 탭. 모든 가격은 VAT 포함 금액이며 30분 단위로 자동 새로고침됩니다.
  • 검색·필터 : 바코드번호·브랜드·제품·유통채널 검색, 판매상태(판매중 등), 브랜드, 유통채널, 변경일 선택 / [엑셀 다운로드]
  • 가격표 항목 : 상태, 브랜드, 제품, 바코드번호, 원가, 포장규격, 유통채널(범용·홈쇼핑 전용 등), 구성(수량)·섭취기간별 상시가와 행사(1차·2차)별 가격·원가율
  • 최근 변경 : 최근 가격이 변경된 제품 건수와 내역을 확인할 수 있습니다.
  • 유의 : 대외비 · 사내 전용 자료입니다. 사내 네트워크에서만 접속되며 외부 반출·화면 공유·재배포는 금지입니다.

09

WMS 재고 조회

WMS 재고를 실시간으로 확인하는 메뉴입니다. WMS와 연동되어 로케이션별 실제 재고 정보가 표시됩니다. 별도 안내 페이지 없이 클릭하면 해당 메뉴로 바로 이동합니다.

  • 검색 : ERP번호 또는 바코드번호로 검색합니다. 제품명/상품명(포함·제외), 로케이션(A·B·C·D·M·P·R·S·U·X·Z), 보류여부(Y/N)로 좁힐 수 있습니다.
  • 전체 조회는 불가합니다. WMS DB 조회 정보이므로 전체 조회가 필요하면 화면의 [WMS 바로가기]로 WMS에서 확인하세요.
  • 목록 항목 : ERP번호, 바코드번호, 브랜드, 상품명, 규격, 로케이션, 유통기한, 보류여부, 출고가능량, 재고수량 / [목록 다운로드]
ERP번호바코드번호로케이션별 재고
공통 안내
Tip. 화면의 * 표시는 필수 입력입니다. 하나라도 비어 있으면 저장되지 않습니다. 검색 조건은 선택한 항목을 모두 만족하는 결과만 보여줍니다.
Tip. 쉼표(,) 또는 Enter로 구분해 여러 개를 한 번에 검색할 수 있습니다(바코드·ERP번호 등). 단, 상품명처럼 단어 검색은 입력한 단어가 모두 포함된 경우만 조회됩니다.
주의. 바코드는 한 번 등록·저장하면 수정할 수 없고 중복 등록도 안 됩니다. ERP 번호 1개는 하나의 출고 구조로 고정되므로, 수량별 구성은 반드시 개별 ERP 번호로 생성하세요.
